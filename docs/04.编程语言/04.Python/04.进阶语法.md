# Python 进阶语法

> 基础语法学完后，只需再掌握这几个核心进阶概念，就能应对绝大多数 Python 开发场景。**内容不多，但很重要。**

## 1. lambda 匿名函数（一句话函数）

用一个表达式定义小函数，不需要 `def` 和函数名：

```python
# 传统写法
def add(a, b):
    return a + b

# lambda 等价写法
add = lambda a, b: a + b

print(add(1, 2))   # 3
```

**最常见用途**：传给需要函数的参数（如 `sorted` 的 key）：

```python
students = [("Tom", 18), ("Amy", 20), ("Bob", 15)]

# 按年龄排序（lambda 告诉 sorted 按第 2 个元素排）
students.sort(key=lambda s: s[1])
print(students)   # [('Bob', 15), ('Tom', 18), ('Amy', 20)]
```

**要点**：`lambda 参数: 返回值`，只能写单行表达式。

## 2. 解包 unpacking（`*` 和 `**`）

把列表/字典的元素**展开**赋值或传递。

### 2.1 列表解包 `*`

```python
nums = [1, 2, 3]

print(*nums)      # 1 2 3（等价于 print(1, 2, 3)）

a, *rest = [1, 2, 3, 4]
print(a)          # 1
print(rest)       # [2, 3, 4]
```

### 2.2 字典解包 `**`

```python
def greet(name, age):
    print(f"{name} {age}岁")

info = {"name": "Tom", "age": 18}
greet(**info)     # Tom 18岁（把字典展开成关键字参数）
```

## 3. 装饰器 decorator（`@`）

**不修改函数本身，给函数"加功能"**。核心思想：函数也能当参数传递。

```python
def timer(func):
    """装饰器：给函数加计时功能"""
    def wrapper(*args, **kwargs):
        print(f"开始执行 {func.__name__}")
        result = func(*args, **kwargs)
        print(f"执行完成")
        return result
    return wrapper


@timer            # 给 say_hello 加上 timer 的功能
def say_hello():
    print("你好！")

say_hello()
# 开始执行 say_hello
# 你好！
# 执行完成
```

**用途**：日志、权限检查、计时、缓存——很多框架（Flask、Django）用它。

## 4. 生成器 generator（`yield`）

用 `yield` 实现**惰性生成**数据——需要时才产生，**省内存**。

```python
def countdown(n):
    while n > 0:
        yield n        # 暂停，返回 n；下次调用从这继续
        n -= 1

for num in countdown(3):
    print(num)
# 3
# 2
# 1
```

**对比**：生成器 vs 列表

```python
# 列表：一次性全部生成，占内存
nums = [x for x in range(1000000)]

# 生成器：惰性，每次只产生一个，省内存
gen = (x for x in range(1000000))   # 用 () 不是 []
```

**用途**：处理超大文件、无限序列、流式数据。

## 5. 迭代器 iterator（可遍历对象）

能被 `for` 遍历的对象叫**可迭代对象**（列表、字典、字符串、生成器等）。

理解它的机制：

```python
nums = [1, 2, 3]
it = iter(nums)     # 获取迭代器

next(it)   # 1
next(it)   # 2
next(it)   # 3
# next(it)   # StopIteration 异常（没有更多了）
```

`for` 循环本质就是反复调用 `next()` 直到耗尽。

**要点**：
- `iter(对象)` 得到迭代器
- `next(迭代器)` 逐个取元素
- 生成器天然是迭代器

## 6. 模块与包 import（多文件组织）

把代码拆到多个文件，用 `import` 复用。

### 6.1 导入模块

```python
import math                # 导入整个模块
print(math.sqrt(16))       # 4.0

from math import sqrt      # 只导入某个函数
print(sqrt(16))            # 4.0

import datetime as dt       # 起别名
print(dt.date.today())     # 今天日期
```

### 6.2 导入自己的文件

假设有 `utils.py`：

```python
# utils.py
def add(a, b):
    return a + b
```

另一个文件用：

```python
# main.py
import utils
print(utils.add(1, 2))     # 3
```

> 两个文件放同一目录即可。配合 `if __name__ == "__main__"` 防止被导入时执行副作用代码。

### 6.3 常用标准库

```python
import random    # 随机数
import json      # JSON 数据处理
import datetime  # 日期时间
import math      # 数学函数
import os        # 操作系统（旧 API，新项目用 pathlib）
from pathlib import Path   # 路径（现代推荐）
import re        # 正则表达式
```

## 7. 进阶语法速查

| 概念 | 一句话 | 用在哪 |
| --- | --- | --- |
| `lambda` | 单行匿名函数 | `sorted`/`filter`/`map` 的 key |
| `*args` / `**kwargs` | 接收任意数量参数 | 装饰器、通用函数 |
| `@装饰器` | 不修改函数加功能 | 日志、权限、计时 |
| `yield` | 惰性生成数据 | 大文件、流式处理 |
| `iter()` / `next()` | 手动遍历 | 理解 for 机制 |
| `import` | 复用其它文件 | 项目组织 |
