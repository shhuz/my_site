# Python 入门篇

> 本篇章**面向完全零基础**，用最通俗的方式带你迈出第一步。学完本篇，你能理解"程序是怎么回事"，并运行第一个 Python 程序。

## 0. 写给零基础：Python 是什么？

- Python 是一种**编程语言**——用来告诉计算机"做什么"的指令。
- 它像英语一样**接近自然语言**，所以好读、好写。
- 它被广泛用于：自动化脚本、数据分析、人工智能、Web 开发、工具开发。

**你不需要懂数学或计算机原理**，跟着做就能学会。

---

## 1. 第一个程序：让电脑说你好

用任意文本编辑器（如 VSCode）新建文件 `hello.py`，输入：

```python
print("你好，世界！")
```

运行：

```bash
python hello.py
```

你会看到屏幕输出：

```
你好，世界！
```

**发生了什么？**
- `print(...)` 是 Python 的**输出命令**，作用是把括号里的内容显示到屏幕上。
- 引号里的 `"你好，世界！"` 是**字符串**（就是一段文字）。

## 2. 程序 = 一行一行执行的指令

Python 从上往下逐行执行。看这个例子：

```python
print("第一步")
print("第二步")
print("第三步")
```

运行结果（从上到下）：

```
第一步
第二步
第三步
```

**关键认知**：程序就是"一步步告诉计算机做什么"。

## 3. 用变量"存东西"

变量就像**贴了标签的盒子**，可以放数据，之后随时拿出来用：

```python
name = "小明"      # 把"小明"放进叫 name 的盒子
age = 18          # 把 18 放进叫 age 的盒子

print(name)       # 拿出 name 里的内容 → 小明
print(age)        # 拿出 age 里的内容 → 18
```

**要点**：
- `=` 是**赋值**，把右边的东西放进左边（不是数学里的"等于"）
- 变量名自己起，用字母/数字/下划线，不能以数字开头

## 4. 和程序"对话"：输入

`input()` 让程序停下来等用户输入：

```python
name = input("你叫什么名字？")
print(f"你好，{name}！")
```

运行后程序会问，你输入内容回车：

```
你叫什么名字？小明
你好，小明！
```

- `f"..."` 是**格式化字符串**，花括号 `{name}` 会被替换成变量的值。

## 5. 让程序"判断"：if

程序可以根据条件做不同的事：

```python
age = input("你几岁？")
age = int(age)       # 把输入的字符串转成数字

if age >= 18:
    print("你是成年人")
else:
    print("你是未成年人")
```

**要点**：
- `if 条件:` 后面**必须有冒号**
- 条件成立（True）执行缩进的代码；否则执行 `else` 后的代码
- **缩进**（通常 4 空格）表示"这段代码属于这个 if"

## 6. 让程序"重复"：for

程序可以重复做一件事：

```python
for i in range(3):
    print("第", i, "次")
```

运行：

```
第 0 次
第 1 次
第 2 次
```

- `range(3)` 生成 `0,1,2` 三个数
- 循环体（缩进的代码）会执行 3 次

## 7. 组合起来：猜数字小游戏

把前面学的串起来，做一个能玩的小游戏：

```python
import random          # 引入"随机数"工具

secret = random.randint(1, 10)   # 随机生成 1~10 的秘密数字

print("我心里想了一个 1~10 的数字，你猜猜！")

guess = int(input("你的猜测："))

if guess == secret:
    print("太棒了，猜对了！")
else:
    print(f"猜错了，答案是 {secret}。")
```

运行试试，多玩几次体会 if、变量、输入的综合运用。

## 8. 新手最容易踩的坑

| 报错 | 原因 | 怎么改 |
| --- | --- | --- |
| `SyntaxError` | 拼写/标点错了（如中文冒号） | 检查是否用了英文标点 `:` |
| `IndentationError` | 缩进不对 | 统一用 4 空格缩进 |
| `NameError` | 变量名打错了 | 检查名字是否一致 |
| 中文乱码 | 文件编码问题 | 保存为 UTF-8 编码 |

## 9. 学完本篇，你该做什么？

**动手练**：把上面的代码**亲手打一遍**（不要复制粘贴），然后改着玩：
- 改猜数字的范围（1~100）
- 加一个"猜的次数限制"
- 改输出文字

> 入门最重要的是**自己动手写 + 改**，光看不练没效果。
