# Python 基础语法

本教程覆盖 Python 核心基础语法，掌握后能看懂和编写简单程序。

> 环境：Python 3.x，Ubuntu/Debian 或 Windows 均可。

## 1. 环境搭建

### 1.1 安装 Python

Ubuntu/Debian：

```bash
sudo apt install python3 python3-venv
```

验证：

```bash
python3 --version   # 应显示 Python 3.x
```

### 1.2 创建并激活虚拟环境（推荐）

虚拟环境用于隔离项目依赖：

```bash
cd 项目目录
python3 -m venv .venv        # 创建
source .venv/bin/activate    # 激活（Linux/Mac）
# Windows: .venv\Scripts\activate
```

激活后提示符前出现 `(.venv)`。退出用 `deactivate`。

### 1.3 运行 Python

```bash
python xxx.py      # 运行脚本文件
python             # 进入交互模式
```

## 2. 第一个程序

```python
print("Hello, World!")
```

运行：

```bash
python main.py

```
Hello, World!

## 3. 变量与数据类型

变量**无需声明类型**，直接赋值即可。Python 会自动推断类型。

### 3.1 基本类型

```python
# 数字
age = 30          # 整数 int
pi = 3.14         # 浮点数 float

# 文本
name = "Python"   # 字符串 str

# 布尔
is_ok = True      # 布尔 bool（True / False）

# 空值
nothing = None    # 空值 None
```

### 3.2 查看类型

```python
print(type(age))    # <class 'int'>
print(type(name))   # <class 'str'>
```

### 3.3 类型转换

```python
int("123")       # 123    字符串→整数
str(123)         # "123"  整数→字符串
float("3.14")    # 3.14   字符串→浮点数
bool(0)          # False  0 为假
bool(1)          # True   非 0 为真
```

## 4. 输入与输出

### 4.1 输出 print

```python
print("你好")                # 你好
print("a", "b", "c")         # a b c（空格分隔）
print(1 + 1)                 # 2（可放表达式）
print("值 =", 42)            # 值 = 42
```

### 4.2 格式化输出（f-string）

```python
name = "Tom"
age = 18
print(f"我叫 {name}，今年 {age} 岁")   # 我叫 Tom，今年 18 岁
```

### 4.3 输入 input

```python
name = input("请输入姓名：")   # 等待用户输入
print(f"你好，{name}")
```

> `input` 返回的**永远是字符串**，要当数字需转换：`int(input("输入数字："))`

## 5. 运算符

### 5.1 算术运算符

```python
a, b = 10, 3

a + b   # 13  加
a - b   # 7   减
a * b   # 30  乘
a / b   # 3.333...  除（总是返回浮点数）
a // b  # 3   整除（取商）
a % b   # 1   取余
a ** b  # 1000 幂
```

### 5.2 比较运算符（返回布尔）

```python
a == b    # 等于
a != b    # 不等于
a > b     # 大于
a < b     # 小于
a >= b    # 大于等于
a <= b    # 小于等于
```

### 5.3 逻辑运算符

```python
True and False   # False  与（两边都真才真）
True or False    # True   或（一边真就真）
not True         # False  非（取反）
```

### 5.4 赋值运算符

```python
x = 5
x += 1    # x = 6   （加等）
x -= 1    # x = 5   （减等）
x *= 2    # x = 10  （乘等）
x /= 2    # x = 5.0 （除等）
```

## 6. 条件判断

```python
age = 18

if age >= 18:
    print("成年")
elif age >= 12:
    print("青少年")
else:
    print("未成年")
```

要点：
- `if` / `elif` / `else` 后面必须有**冒号**
- 代码块用**缩进**表示（通常 4 空格），缩进一致才属于同一块

### 6.1 match 语句（Python 3.10+，现代写法）

`match` 是 Python 3.10 引入的**模式匹配**，比 `if/elif` 更适合多分支比较：

```python
command = "start"

match command:
    case "start":
        print("开始")
    case "stop":
        print("停止")
    case _:          # 下划线 = 默认分支（相当于 else）
        print("未知命令")
```

> `match` 是 3.10+ 才有的现代特性，能替代简单的 `if/elif/else` 链，更清晰。若用 Python 3.10 以下，需用 `if/elif/else`。

## 7. 循环

### 7.1 for 循环（遍历）

```python
# 遍历数字范围 range(开始, 结束, 步长)，结束不包含
for i in range(5):          # 0,1,2,3,4
    print(i)

for i in range(1, 6):       # 1,2,3,4,5
    print(i)

for i in range(0, 10, 2):   # 0,2,4,6,8
    print(i)
```

### 7.2 while 循环

```python
n = 0
while n < 3:
    print(n)
    n += 1        # 记得更新条件，否则死循环
```

### 7.3 跳出循环

```python
# break：结束整个循环
for i in range(10):
    if i == 3:
        break     # 到 3 就停
    print(i)      # 输出 0,1,2

# continue：跳过本次
for i in range(5):
    if i == 2:
        continue  # 跳过 2
    print(i)      # 输出 0,1,3,4
```

### 7.4 同时拿到索引和值（enumerate，现代写法）

遍历列表时想同时拿到下标和值，用 `enumerate`，**不用** `range(len(...))`：

```python
fruits = ["苹果", "香蕉", "橙子"]

for index, fruit in enumerate(fruits):
    print(index, fruit)
# 0 苹果
# 1 香蕉
# 2 橙子
```

## 8. 字符串操作

```python
s = "Hello, Python"

len(s)          # 13  长度
s.upper()       # "HELLO, PYTHON"  大写
s.lower()       # "hello, python"  小写
s.strip()       # 去掉首尾空格
s.replace("l", "L")   # 替换
s.split(",")    # ['Hello', ' Python']  按逗号拆分成列表
",".join(["a","b"])   # "a,b"  用逗号连接列表
"Hello" in s    # True  是否包含子串
s[0]            # "H"  取第 1 个字符（下标从 0 开始）
s[0:5]          # "Hello"  切片（取前 5 个）
```

## 9. 列表 list

列表是有序、可修改的集合，用 `[]`：

```python
nums = [1, 2, 3, 4]

nums[0]          # 1       按下标取
nums[-1]         # 4       取最后一个
nums[1:3]        # [2,3]   切片
len(nums)        # 4       长度

nums.append(5)   # 末尾加元素  → [1,2,3,4,5]
nums.insert(0, 0)# 指定位置插入 → [0,1,2,3,4,5]
nums.remove(2)   # 删除第一个值为 2 的元素
nums.pop()       # 删除并返回最后一个
nums.sort()      # 排序

# 遍历列表
for n in nums:
    print(n)

# 判断是否包含
if 3 in nums:
    print("有 3")
```

## 10. 元组 tuple

元组是**不可修改**的列表，用 `()`：

```python
t = (1, 2, 3)
t[0]        # 1  可取
# t[0] = 9  # 报错！元组不可修改

a, b, c = t   # 解包：a=1, b=2, c=3
```

## 11. 字典 dict

字典是「键值对」集合，用 `{}`：

```python
person = {"name": "Tom", "age": 18}

person["name"]        # "Tom"    取值
person["age"]         # 18
person.get("name")    # "Tom"    取值（不存在返回 None）
person["city"] = "BJ" # 新增键值对

"name" in person      # True  判断键是否存在
list(person.keys())   # ['name','age','city']  所有键（转成列表）
list(person.values()) # ['Tom',18,'BJ']        所有值

# 遍历键（现代写法：直接遍历字典，无需 list()）
for key in person:
    print(key)

# 遍历键值对
for key, value in person.items():
    print(key, value)
```

## 12. 函数

函数用 `def` 定义，封装可复用逻辑：

```python
def add(a, b):
    """返回 a 与 b 的和（文档字符串）"""
    return a + b

result = add(1, 4)
print(result)   # 5
```

### 12.1 默认参数

```python
def greet(name, greeting="你好"):
    return f"{greeting}, {name}"

greet("Tom")          # 你好, Tom
greet("Tom", "Hi")    # Hi, Tom（覆盖默认值）
```

### 12.2 多个返回值

```python
def calc(a, b):
    return a + b, a - b    # 返回元组

s, d = calc(10, 3)   # s=13, d=7
```

### 12.3 变量作用域

```python
x = 10        # 全局变量

def f():
    y = 5     # 局部变量（只能在函数内用）

# print(y)    # 报错！y 在函数外不可见
```

## 13. 面向对象基础（class）

面向对象把「数据」和「操作数据的方法」封装成一个**类（class）**。Python 中一切皆对象。

### 13.1 定义和使用类

```python
class Dog:
    """狗类"""

    def __init__(self, name, age):
        """构造函数：创建对象时自动调用"""
        self.name = name   # self.xxx = 对象的属性
        self.age = age

    def bark(self):
        """方法：对象能做的动作"""
        print(f"{self.name} 在叫：汪汪！")


# 创建对象（实例化）
d = Dog("旺财", 3)

# 访问属性
print(d.name)   # 旺财
print(d.age)    # 3

# 调用方法
d.bark()        # 旺财 在叫：汪汪！
```

要点：
- `__init__` 是**构造方法**，创建对象时自动执行，用来初始化属性
- `self` 代表**对象自身**，所有方法第一个参数都是 `self`
- 属性用 `self.属性名` 定义，方法是类里的函数

### 13.2 属性默认值和修改

```python
class Person:
    def __init__(self, name):
        self.name = name
        self.age = 0        # 默认属性

p = Person("Tom")
p.age = 18      # 修改属性
print(p.age)    # 18
```

### 13.3 `__str__`（打印友好显示）

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        """定义 print(对象) 时显示什么"""
        return f"Point({self.x}, {self.y})"

p = Point(1, 2)
print(p)   # Point(1, 2)（而不是 <__main__.Point object>）
```

### 13.4 继承（复用已有类）

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print("...")

# Cat 继承 Animal，拥有它的所有方法和属性
class Cat(Animal):
    def speak(self):          # 重写父类方法
        print(f"{self.name} 在叫：喵~")

c = Cat("咪咪")
c.speak()   # 咪咪 在叫：喵~（用了父类的 name 属性）
```

### 13.5 何时用 class？

简单脚本用函数即可。**当需要把多个相关数据和操作绑定在一起、且要创建多个相似对象时**，用类更清晰。例如：学生管理系统、游戏角色、银行账户。

## 14. 异常处理基础

```python
try:
    n = int(input("输入数字："))
    print(10 / n)
except ValueError:
    print("输入的不是数字")
except ZeroDivisionError:
    print("不能除以 0")
else:
    print("没有出错才执行")
finally:
    print("无论是否出错都执行")
```

## 15. `if __name__ == "__main__"`

用于区分「直接运行」和「被导入」：

```python
def main():
    print("程序入口")

if __name__ == "__main__":
    main()
```

- 直接运行本文件 → `__name__ == "__main__"`，执行 `main()`
- 被其他文件 `import` → 不执行，避免副作用

## 16. 常用函数速查

```python
len(x)        # 长度（字符串/列表/元组/字典）
range(n)      # 生成 0~n-1 的数字序列
type(x)       # 查看类型
int() / str() / float()   # 类型转换
print()       # 输出
input()       # 输入
max(1,2,3)    # 最大值
min(1,2,3)    # 最小值
abs(-5)       # 绝对值 → 5
sum([1,2,3])  # 求和 → 6
round(3.14159, 2)  # 四舍五入到 2 位 → 3.14
enumerate(列表)  # 遍历时同时得到下标和值（现代写法）
zip(列表A, 列表B) # 并行遍历两个列表
sorted(列表)    # 返回排序后的新列表（不改原列表）
any([True, False])  # 任一为真 → True
all([True, True])   # 全部为真 → True
```

### 16.1 列表推导式（现代写法）

用一行生成列表，替代手写 `for` + `append`：

```python
# 生成 0~9 的平方
squares = [x**2 for x in range(10)]
# [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# 带条件的推导式：只留偶数
evens = [x for x in range(10) if x % 2 == 0]
# [0, 2, 4, 6, 8]
```

> 列表推导式是现代 Python 的核心写法，比手写循环更简洁，也更符合 Python 风格。

## 17. 常见错误

| 错误 | 原因 | 解决 |
| --- | --- | --- |
| `IndentationError` | 缩进不一致 | 统一用 4 空格 |
| `SyntaxError: expected ':'` | 漏了冒号 | `if`/`for`/`def` 后加 `:` |
| `NameError: name 'x' is not defined` | 变量未定义/拼写错 | 检查变量名 |
| `TypeError` | 类型不匹配 | 用 `int()`/`str()` 转换 |
| `IndexError` | 下标越界 | 检查 `len()` 长度 |
| `KeyError` | 字典键不存在 | 用 `.get()` 代替 `[]` |
