# Python 常用操作

日常开发中高频使用的操作，按场景整理。

## 1. 虚拟环境

隔离项目的依赖，避免污染系统 Python。

```bash
cd xxx(项目根目录)

# 创建虚拟环境
python3 -m venv .venv

# 激活
source .venv/bin/activate        # Linux / Mac
# .venv\Scripts\activate         # Windows

# 退出
deactivate

# 删除虚拟环境（重建用）
rm -rf .venv
```

> 激活后提示符前出现 `(.venv)`，此时 `python` / `pip` 都指向虚拟环境内版本。

## 2. pip 管理包

```bash
pip install 包名              # 安装最新版
pip install 包名==1.2.3       # 安装指定版本
pip install 包名>=1.0,<2.0    # 版本范围
pip uninstall 包名            # 卸载
pip list                      # 列出已装包
pip show 包名                 # 查看包详情
pip check                     # 检查依赖冲突
```

## 3. pip 换国内镜像（加速）

默认 pip 源在国外，下载慢。换成国内镜像：

```bash
# 临时使用
pip install 包名 -i https://pypi.tuna.tsinghua.edu.cn/simple

# 永久配置（推荐）
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

常用镜像源：

| 镜像   | 地址                                              |
| ------ | ------------------------------------------------- |
| 清华   | `https://pypi.tuna.tsinghua.edu.cn/simple`      |
| 阿里云 | `https://mirrors.aliyun.com/pypi/simple`        |
| 腾讯云 | `https://mirrors.cloud.tencent.com/pypi/simple` |

## 4. requirements.txt

把项目依赖固化到文件，便于别人复现环境。

现代方式用 `pipreqs`（**只导出代码实际 import 的依赖**，比 `pip freeze` 干净）：

```bash
# 安装 pipreqs
pip install pipreqs

# 导出项目实际用到的依赖
pipreqs 项目目录 --force

# 按文件安装（新环境复现）
pip install -r requirements.txt
```

> `--force` 表示覆盖已有 requirements.txt。`pip freeze` 会导出整个环境所有包（含无关依赖），`pipreqs` 更精确。

## 5. 文件读写

```python
# 读文件
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()  # 整个读为字符串
    # 逐行读: for line in f:

# 写文件
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("内容\n")

# 追加
with open("out.txt", "a", encoding="utf-8") as f:
    f.write("追加的内容\n")
```

> `with` 会自动关闭文件，无需手动 `close()`。
> 中文文件务必加 `encoding="utf-8"`，否则乱码。

## 6. 命令行运行与参数

现代方式用标准库 `argparse`（自动解析、带 `--help`、支持类型校验），**不用**手写 `sys.argv`：

```python
# main.py
import argparse

def main():
    parser = argparse.ArgumentParser(description="示例程序")
    parser.add_argument("--name", required=True, help="姓名")
    parser.add_argument("--age", type=int, default=18, help="年龄")
    args = parser.parse_args()

    print(f"姓名: {args.name}, 年龄: {args.age}")

if __name__ == "__main__":
    main()
```

运行：

```bash
python main.py --name Tom --age 20
# 姓名: Tom, 年龄: 20

python main.py --help
# 自动生成用法说明
```

> `argparse` 是标准库自带，无需安装。需要更简洁的库可了解 `click` / `typer`。

## 7. 调试技巧

```python
# 1. print 打印变量（最简单）
print(f"变量值: {x}")

# 2. 交互式调试：临时插入，运行时进入断点
import pdb

pdb.set_trace()  # 运行到此处暂停，可单步查看

# 3. 运行时进入交互模式（调试异常用）
import traceback

try:
    risky()
except Exception:
    traceback.print_exc()  # 打印完整堆栈
```

## 8. 路径操作

现代方式用标准库 `pathlib`（跨平台、简洁），**不用** `os.path` 字符串拼接：

```python
from pathlib import Path

# 当前目录
cwd = Path.cwd()
print(cwd)

# 拼接路径（用 / 运算符，跨平台）
p = Path("data") / "sub" / "file.txt"

# 判断存在
Path("data.txt").exists()

# 文件名 / 后缀
Path("data/file.txt").name      # 'file.txt'
Path("data/file.txt").suffix    # '.txt'
Path("data/file.txt").parent    # 'data'

# 创建目录（存在也不报错）
Path("new_dir").mkdir(parents=True, exist_ok=True)

# 遍历目录
for f in Path(".").iterdir():
    print(f)

# 查找所有 .py 文件
for f in Path(".").glob("*.py"):
    print(f)
```

> `pathlib` 是 Python 3.4+ 标准库，官方推荐现代写法。`os.path` 属于旧 API，新代码一律用 `pathlib`。

## 10. 常见环境问题

| 问题                    | 解决                          |
| ----------------------- | ----------------------------- |
| 下载包慢/超时           | 换国内镜像（见 §3）          |
| `ModuleNotFoundError` | `pip install 包名`          |
| 权限错误                | 先激活 venv，别用系统 pip     |
| 装了却 import 不到      | 确认激活的 venv 和 pip 一致   |
| pip 版本太老            | `pip install --upgrade pip` |
