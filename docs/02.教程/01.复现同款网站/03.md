# 修改侧边栏插件：让第二层目录独立侧边栏

默认插件只让**顶层目录**（如 `教程/`）独立成侧边栏，第二层（如 `教程/01.xx教程/`）会被并进顶层侧边栏里。需改造插件，让第二层目录也各自独立。

**本文提供两种方式**：
- **方式一（推荐）**：直接用现成的补丁文件，不手动改代码，最简。
- **方式二**：手动改插件源码，再生成补丁（理解原理时用）。


## 方式一：直接用补丁复现（推荐）

补丁文件已生成好：`/patches/vitepress-plugin-sidebar-resolve.patch`。只需保证它存在，并在 `package.json` 配好 `postinstall`。


### 1. 安装 patch-package
```bash
bun add -D patch-package
```


### 1. 配置 postinstall

在 `package.json` 里加（关键，否则 `bun install` 不会自动打补丁）：

```json
"scripts": {
    "postinstall": "patch-package"
}
```


### 2. 安装生效

```bash
bun install        # 自动跑 postinstall → 自动应用补丁
bun run docs:dev
```

**之后每次 `bun install` 都会自动重打补丁，独立侧边栏不丢失，无需手动改插件。**

## 方式二：手动改插件源码 + 生成补丁

### 为什么

插件核心函数 `createFilePathSidebar` 里，`readDirPaths` **只读取第一层子目录**，所以只有顶层目录能成为独立侧边栏 key。要让第二层独立，就对每个顶层目录**再往下扫一层**。

### 1. 改插件源码

**文件**：`node_modules/vitepress-plugin-sidebar-resolve/dist/index.mjs`

在 `createFilePathSidebar` 的 `dirPaths.forEach` 之前，新增函数：

```js
const buildSecondLevelSidebar = (dirPath, dirKey) => {
  const subDirs = readDirPaths(dirPath, ignoreList);
  subDirs.forEach((subDir) => {
    const subName = basename(subDir);
    const subItems = createSidebarItems$1(subDir, option, `${dirKey}${subName}/`);
    if (!ignoreWarn && !subItems.length) return;
    const { name, title } = resolveFileName(subName, subDir, indexSeparator);
    const info = getInfoFromMarkdownDir(subDir, subName);
    const mdTitle = titleFormMd ? info.title : "";
    const subText = (info.prefix && (prefixTransform?.(info.prefix) ?? info.prefix)) ?? ""
      + (mdTitle || title);
    const subItem = {
      text: subText,
      collapsed: typeof collapsed === "function" ? collapsed(dirKey + name, subText) : collapsed,
      items: subItems
    };
    const subKey = `${dirKey}${subName}/`;
    if (isSidebarObject) {
      sidebarObj[subKey] = initItems ? [{ ...subItem, text: initItemsText ? subText : "" }] : subItems;
    } else sidebarArray.push(subItem);
  });
};
```

在 `dirPaths.forEach` 循环末尾调用它：

```js
dirPaths.forEach((dirPath) => {
  // ... 原有逻辑 ...
  buildSecondLevelSidebar(dirPath, `${key}${fileName}/`);  // 新增
});
```

> 函数内不再调用自己，所以**只加一层**，第三层及更深不会单独成 key。

### 2. 生成补丁文件

```bash
cp node_modules/vitepress-plugin-sidebar-resolve/dist/index.mjs /tmp/index.mjs.modified

mkdir -p /tmp/sidebar_orig && cd /tmp/sidebar_orig
curl -sL "https://registry.npmjs.org/vitepress-plugin-sidebar-resolve/-/vitepress-plugin-sidebar-resolve-1.2.3.tgz" -o pkg.tgz
tar -xzf pkg.tgz

mkdir -p patches
diff -u /tmp/sidebar_orig/package/dist/index.mjs /tmp/index.mjs.modified \
  > patches/vitepress-plugin-sidebar-resolve.patch
```

> 需把补丁头部临时路径改成标准格式：`--- a/node_modules/...` 和 `+++ b/node_modules/...`。

### 3. 配置 postinstall 并验证

```json
"scripts": {
  "postinstall": "patch -p1 --batch -f --forward < patches/vitepress-plugin-sidebar-resolve.patch || true"
}
```

```bash
patch -p1 --batch -f --forward < patches/vitepress-plugin-sidebar-resolve.patch
grep -c "buildSecondLevelSidebar" node_modules/vitepress-plugin-sidebar-resolve/dist/index.mjs
# 输出 2 表示成功
```
