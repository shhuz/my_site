# 快速创建初始模板

### 推荐使用

Windows 使用 wsl

Linux 使用 podman 容器


***

### 创建项目目录

```bash
cd ~
mkdir my_site && cd my_site
```

***

## 使用 bun + VitePress


### 安装 bun

bun 是包管理器兼运行时，用于安装依赖和运行脚本。
```bash
sudo apt update
sudo apt install unzip
curl -fsSL https://bun.net.cn/install | bash
source ~/.bashrc
bun --version
```

如需后续升级：
```bash
bun upgrade
```


### 使用 bun 安装 VitePress

```bash
bun add -D vitepress@next
```


## 构建一个基本项目

```bash
bun vitepress init
```
第一个选项：
◇  Where should VitePress initialize the config?
│  ./

输入 ./docs
其它全部默认，直接按 Enter


## 查看页面

启动开发服务器
```bash
bun run docs:dev
```

之后用浏览器打开 " ➜  Local: " 显示的网页地址，就能看到页面内容
