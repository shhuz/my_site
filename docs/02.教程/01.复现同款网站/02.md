# 自动更新排版侧边栏


VitePress 本身不自带自动侧边栏生成功能，可以使用插件
---

## 插件选择：`vitepress-plugin-sidebar-resolve`

自动生成侧边栏设计


### 安装与配置

安装插件
```bash
bun add -D vitepress-plugin-sidebar-resolve
```

修改 "./docs/.vitepress/config.mts" 文件，添加以下内容
```typescript
//自动生成侧边栏插件
import Sidebar from 'vitepress-plugin-sidebar-resolve'

export default defineConfig({
  vite: {
    plugins: [
      Sidebar({//侧边栏插件配置
        path: '.',               // 扫描 Docs 文档根
        titleFormMd: true,       // 取一级标题作为侧边栏文字
        initItems: false,        // 直接显示文件列表，不包包括分组
        collapsed: true,         // 默认折叠

      })
    ],
  },
  // 不需要再手动配置 themeConfig.sidebar！
})
}
```
