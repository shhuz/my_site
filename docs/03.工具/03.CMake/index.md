# CMake 教程

[原文地址](https://cmake.org/cmake/help/latest/)

## 介绍

CMake 教程提供了一份分步指南，涵盖 CMake 可帮助解决的常见构建系统问题。通过示例项目了解各个主题如何协同工作将非常有帮助。

## 步骤

教程源代码示例可在本归档文件中获取。每个步骤都有各自的子目录，包含可用作起点的代码。教程示例是递进式的，因此每个步骤都提供前一步骤的完整解决方案。
